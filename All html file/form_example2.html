🧪 রেডিও বাটন : শুধু radio vs label সহ radio

নিচের দুটি গ্রুপে ক্লিক করে দেখুন পার্থক্য। লেখার উপর ক্লিক করুন – ফলাফল নিজেই বুঝে যাবেন।

❌ গ্রুপ A: শুধু <input type="radio"> (label ছাড়া)

👉 আপনার পছন্দের ফল নির্বাচন করুন (শুধু ছোট বৃত্তে ক্লিক করুন):

আপেল
কলা
আম
⚠️ চেষ্টা করুন: "আপেল", "কলা", "আম" – এই লেখাগুলোতে ক্লিক করুন। দেখবেন কিছু হয় না।
✅ শুধু ছোট গোল বৃত্তে ক্লিক করলেই সিলেক্ট হবে।
✅ গ্রুপ B: <label> + <input type="radio">

👉 আপনার পছন্দের রং নির্বাচন করুন (লেখায় ক্লিক করলেও হবে):



✨ চেষ্টা করুন: "লাল", "সবুজ", "নীল" – এই লেখাগুলোতে ক্লিক করুন। দেখবেন রেডিও বাটন নিজে থেকেই সিলেক্ট হয়ে যাচ্ছে!
✅ গ্রুপ C: <label for="..."> + id (এটিও label-ই)

👉 পছন্দের প্রাণী (লেখায় ক্লিক করুন):



✨ এখানেও "বিড়াল", "কুকুর", "গরু" লেখায় ক্লিক করলেই রেডিও সিলেক্ট হয়।
📌 মূল কথা:
  • শুধু <input type="radio"> → কেবল ছোট গোল জায়গায় ক্লিক কাজ করে।
  • <label> ব্যবহার করলে → পাশের লেখায় ক্লিক করলেও রেডিও সিলেক্ট হয়। এতে ক্লিক করার এলাকা বড় হয়, আর স্ক্রিন রিডার ব্যবহারকারীরাও বুঝতে পারেন।
  • দুটো পদ্ধতি আছে: <label> <input> টেক্সট </label> অথবা <input id="x"> <label for="x">টেক্সট</label>
🔁 উপরের গ্রুপ A-তে লেখায় ক্লিক করে দেখুন → সিলেক্ট হয় না। গ্রুপ B বা C-তে লেখায় ক্লিক করুন → সিলেক্ট হয়। এটাই পার্থক্য।
